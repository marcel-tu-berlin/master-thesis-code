# Run evidence

New E0-E2 results belong here. The active protocol is
[the final E0-E2 campaign](../../docs/plans/e0-e2-campaign.md).

All development evidence through 2026-09-24 is preserved under
[`archive/development-2026-09-24/`](archive/development-2026-09-24/README.md).
Do not reuse archived experiment IDs or treat moving a directory as permission
to overwrite or rerun its experiment.

`RUNNING.md` at the repository root is the only source of live GPU state.
Planned experiment configs belong in `pipeline/configs/`; finished and
superseded configs belong in `pipeline/configs/archive/`.
