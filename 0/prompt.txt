   **The e27 retrain regression, traced to ground.** Sequence of probes, each isolating one variable:
   - `e27retrain-oldseeds` (new policy, old seeds) vs `e27paired-oldseeds` (old policy, old seeds): click-menu-2 0.660 → 0.480, lost 9 gained 0, p=0.004. Policy effect -0.18, seed effect -0.08.

   - Traced every training-path change in `8a01cc8`: `max_tool_calling_iterations` unchanged for browsergym (both versions pass 8), reward changes to unused components, frozen configs differ by one eval-only key. Only `seed_base=seed_block(seed)` remained.
   - `e27rep2` (byte-identical config, same seed): held_out 0.650 → 0.560. **Run nondeterminism alone moves 9pp.**

   **Root cause found:** `batch_size` defaults to 1, so each optimizer step is one prompt-group of 8 rollouts. When those 8 share a correctness label the step has zero advantage variance. Measured: ~50% of steps carry no gradient across all three e27 runs.
