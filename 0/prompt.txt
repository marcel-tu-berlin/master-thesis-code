   - **`pipeline/eval/agentic_eval.py`** (MODIFIED) - the load-bearing change. Added above `_parse_answer`:
     ```python
     def _iter_tool_payloads(text: str):
         """Yield each tool-call payload dict the model emitted, in order.

         Two wire formats, because the study runs two model lineages. Qwen3 wraps
         calls in Hermes `<tool_call>` tags; Llama 3.x emits a bare JSON object with
         no tags at all. Tagged matches take priority and short-circuit the rest, so
         a model that emits tags is parsed exactly as it was before this existed and
         the untagged scan only runs when there were none to find.

         Training does not need this - TRL's `parse_response` normalises both from
         the token ids. Eval parses the decoded text itself, so it has to agree.

         One deliberate difference from TRL: its `llama3_schema` regex is anchored at
         `^`, so a call preceded by prose is training-invisible and never executed.
         The scan below is unanchored, which matches how the Hermes branch has always
         treated Qwen (`finditer` over the whole completion) and keeps the two
         lineages scored by one rule. It does mean eval credits a prose-prefixed call
         that training would have dropped - relevant mainly to the untrained E0 arms,
         which have not yet learnt to lead with the call.
         """
         tagged = False
         for m in _TOOL_CALL_RE.finditer(text):
             try:
                 payload = json.loads(m.group(1))
             except (ValueError, TypeError):
                 continue
             if isinstance(payload, dict):
                 tagged = True
                 yield payload
         if tagged:
             return

         # Untagged JSON can start anywhere in the completion, and a brace-matching
         # regex gets this wrong on nested objects. `raw_decode` from each `{` is the
         # stdlib's own scanner, so it stops at the right brace by construction.
         decoder = json.JSONDecoder()
         for i, ch in enumerate(text):
             if ch != "{":
                 continue
             try:
                 payload, _ = decoder.raw_decode(text, i)
             except ValueError:
                 continue
             if isinstance(payload, dict) and "name" in payload:
                 yield payload

     def _call_args(payload: dict) -> dict:
         """The argument object of a tool call, under either lineage's key.

         Qwen/Hermes calls it `arguments`, Llama 3.x calls it `parameters`. A payload
         whose args are neither absent nor a dict (a model emitting them
         pre-serialized, say) reads as no arguments rather than raising.
         """
         args = payload.get("arguments")
         if args is None:
             args = payload.get("parameters")
         return args if isinstance(args, dict) else {}
     ```
     And both parsers rewritten to route through them:
     ```python
     def _parse_answer(text: str) -> str | None:
         """Return the answer from the first valid `answer` tool call, else None."""
         for payload in _iter_tool_payloads(text):
             if payload.get("name") == "answer":
                 ans = _call_args(payload).get("answer")
                 if ans is not None:
                     return str(ans)
         return None

     def _parse_tool_call(text: str) -> tuple | None:
         """Return (name, arguments) from the FIRST valid tool call, else None.

         General form used by the multi-turn loop (any tool name). The single-step
         reasoning_gym path keeps its own _parse_answer (first `answer` call only).
         """
         for payload in _iter_tool_payloads(text):
             name = payload.get("name")
             if name is not None:
                 return str(name), _call_args(payload)
         return None
     ```
