   - **Regression-as-invalidation:** in this repo a silent behaviour change does not break a feature, it invalidates results already on disk. Measurement semantics (token counting, correctness threshold, seed mapping, budget accounting, metric definitions) are the protected surface.

Dropping `reasoning_content` measured 18 tokens of a 1024-token completion (~2%). Preferring `len(completion_ids)` branched on whether TRL had interleaved a tool message — which happens exactly when the model called a tool — so the ruler became a proxy for correctness.
   - **`SEED_BLOCK = 1_000_000`:** question seed = `config_seed * SEED_BLOCK + offset`; `_EVAL_SEED_OFFSET = 100_000` lives inside the block. Before this, `--seeds 42 43` shared ~99% of questions.
   - **Whole-trajectory generation budget:** eval charges interleaved tool responses against it, matching training. Per-turn application let an episode generate `max_turns` × the training budget.
   - **Gradient-coverage asymmetry:** under `advantage_weighted`, a zero-within-group-variance group trains on nothing. Adding any varying component (cosine) makes every group live: 40.7% vs 99.5% live groups in the e24bs4/e25bs4 pair.
   - **Per-run percentile thresholds:** under/overthinking rates are not cross-arm comparable unless pinned via `load_reference_thresholds`.

   - **OpenEnv server contract:** `create_app` must take `max_concurrent_envs` from `MAX_CONCURRENT_ENVS` and the env class must set `SUPPORTS_CONCURRENT_SESSIONS = True`, or the server closes every WebSocket session after the first; `reset(seed=N)` must be deterministic in N or rollout slots sharing a server get different questions and the GRPO group is not a group (fails silently).
