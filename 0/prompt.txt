2. Key Technical Concepts:
   - **`CosineLengthReward` (Wu/Yeo 2025)**: `progress = min(n_tokens/max_len, 1)`, `c = cos(progress*pi)`. Correct: short=1.0, long=0.5. Wrong: short=-1.0, long=-0.5. **Wrong-and-long pays more than wrong-and-short by construction** - this is the mechanism behind E2's truncation increase.
   - **`frac_reward_zero_std`**: TRL metric, fraction of prompt-groups with zero within-group reward variance. Such a group yields zero advantage and trains on nothing. A component that adds within-group variance buys its arm more live gradient than the control gets.
   - **`hit_generation_cap` semantics**: fires when `budget <= 0` at loop start OR when a turn's `n_tok >= turn_cap`. Tool feedback charges the trajectory budget but is NOT added to `n_tokens`, so a cap episode can record n_tokens < 4096 (observed: 3266, 3375, 3521).
   - **Family assignment by seed parity**: `tasks[seed % len(tasks)]` in `domains/browsergym/adapter.py:reset()`. Even seed -> first task, odd -> second. This is what made the per-family decomposition possible.
   - **Seed blocks**: question seed = `config_seed * SEED_BLOCK + offset`, `SEED_BLOCK = 1_000_000`. Eval offset `_EVAL_SEED_OFFSET = 100_000`. New scheme gives 42100000..; the pre-fix scheme gave `seed + offset` = 100042.. - the discriminator for whether a run is paired with the bs4 campaign.
   - **`unsupported_claim_rate`** = fraction of terminated episodes with `len(tool_calls) == 1` (i.e. `max(len-1,0) == 0`), computed in `eval/metrics.py:~226`. Degenerate on browsergym (only `click` and `noop`, no distinguished terminal call).
   - **The batch_size confound**: `a19b1ff` changed `grpo_runner`'s default from `t.get("batch_size", 1)` to `4`. Runs before it trained at 1 prompt-group per optimizer step. A config stating `batch_size: 4` does not mean the *run* used it.
   - **Statistical methodology** (from the e24bs4/e25bs4 precedent): difference-of-medians, median-of-per-question-differences, mean-of-per-question-differences, all with 20k paired bootstrap CIs (RNG seeded at 0), plus exact-binomial sign test and exact-binomial McNemar on discordant pairs.
   - **Tooling gotchas re-encountered**: `pgrep -f <pattern>` self-matches the checking shell (use `kill -0 <pid>` instead); ssh prints a large banner requiring `| tail`; `cd` persists between Bash calls; `rtk` proxies commands and can truncate output (`head -1` on a jsonl printed "[100 more lines]").
