2. **Key Technical Concepts:**
   - **`frac_reward_zero_std`** — TRL metric: fraction of prompt-groups in a step with zero within-group reward variance, hence zero advantage and no gradient. At `batch_size: 4` it takes values {0, 0.25, 0.5, 0.75, 1.0}; a value of 1.0 means the whole step is dead.
   - **Gradient-coverage arithmetic:** per-group dead probability is a task property that batch size cannot change; raising batch size only makes an all-dead *step* rare (p_dead^batch_size).
   - **Saturation as the cause of dead groups:** poly at a 4096 budget has `EnvReward/raw_mean` ≈ 0.94, so most groups are all-8-correct → identical reward → zero advantage under `advantage_weighted` z-scoring.
   - **The gradient-matching asymmetry (new finding):** any reward component with within-group variance (cosine length) makes every group live. e25bs4 trained on 99.5% of groups vs e24bs4's 40.7% — the treatment arm got ~2.4x the live gradient, so the contrast is "cosine + more gradient", not cosine alone.
   - **Accuracy == termination at the 4k cap:** zero wrong-and-terminated episodes in *both* arms; every wrong episode stops at exactly 4096 tokens with `hit_generation_cap`; `non_termination_rate` equals `1 - accuracy` to the digit.
   - **Composition confound in unpaired token means:** e25bs4's correct-episode mean *rose* (720.0 → 783.7) while the paired median *fell*, because the treatment arm solves 5 extra (long) questions. Paired-on-common-seeds is the valid contrast.
   - **Box query pattern:** the exalsius DevPod MOTD banner floods every ssh; solved with `ssh gpu-l4 'echo "===MARK==="; ...' 2>/dev/null | sed -n '/===MARK===/,$p'`, and for multi-line remote scripts `ssh gpu-l4 'bash -s' <<'REMOTE' ... REMOTE` to avoid quoting escapes.
   - **Background watcher pattern:** Bash `run_in_background` with an until-loop that exits on the first of {success condition, process gone, traceback, deadline} — one notification, and silence never reads as success. Tolerates VPN drops because an unreachable box yields an empty probe string that just re-loops.
